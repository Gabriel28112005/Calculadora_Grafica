# Calculadora (MVC)

## Descripción

Aparecerá una interfaz gráfica en donde el usuario podrá realizar operaciones básicas (suma, resta, multiplicación y división de enteros). Además, para versiones futuras, el usuario dispondrá en la parte superior izquierda de un menú en donde seleccionar entre una calculadora básica (la que aparece por defecto), una de matrices de orden 2 y una de matrices de orden 3. Las calculadora matriciales no están actualmente disponibles
